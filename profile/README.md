# oalive

팀의 간이 프로젝트와 프로덕트를 함께 만들고 관리하는 공간입니다.

## 시작하기

- 새 프로젝트는 [`product-template`](https://github.com/oalive/product-template) 저장소의 **Use this template** 버튼으로 만들어 주세요.
- 작업 방식과 규칙은 [기여 가이드](https://github.com/oalive/.github/blob/main/CONTRIBUTING.md)를 참고해 주세요.

## 저장소 이름 규칙

`프로젝트명-역할` 형태로, 소문자와 하이픈(-)만 사용합니다.

예: `checkout-web`, `checkout-api`, `survey-bot`
